Projet Vedette

ReplAI stats

Production-Ready
JavaScript (Vanilla) HTML5 / CSS3 IndexedDB Web Camera API Node.js Tools

ReplAI stats est une application web innovante permettant la saisie en direct de statistiques de match. Conçue pour offrir une réactivité maximale sur le terrain, elle intègre des fonctionnalités avancées de captures vidéo en temps réel, de génération de compilations de temps forts, ainsi que l'exportation instantanée de fiches de statistiques sous forme d'images, de fichiers PDF et de stories prêtes à être partagées sur les réseaux sociaux.

💡 Performance & Conception :

Défi technique relevé : l'application fonctionne de manière totalement native dans le navigateur. Aucune étape de build, aucun framework encombrant, aucun npm. Les données volumineuses (clips vidéos, photos des équipes) sont stockées localement de manière ultra-performante grâce à une architecture basée sur IndexedDB.
